# 年辽的知识工作台

数字私人书房 + 编辑工作室 · 纯前端应用：本机双击可用，也可部署成全网可访问的网页。

## 两种用法
- **本机**：双击 `index.html`，数据存浏览器 localStorage，零依赖。
- **网页版**（GitHub Pages 托管 + GitHub Gist 多端同步 + 阿里云函数计算中转千问）：
  全程步骤见 **[DEPLOY.md](DEPLOY.md)**。手机浏览器打开网址 →「添加到主屏幕」即为独立 App；
  内置 Service Worker 离线缓存，在线取最新、断网照样打开。

## 五大入口 + 设置
| 入口 | 用途 |
|---|---|
| 书房今日 | 一周排期条、当日任务（逾期置顶）、灵感速记、进行中项目 |
| 四大分区 | 药剂学研究 / 日记写作 / AI药学自学 / AI视频自媒体，各区项目与待办 |
| 灵感库 | 随手记录，自动归类 + 抽标签，可按类筛选 |
| 资料归档 | 文献、课程、模板、链接、手记，自动抽取检索关键词 |
| 全文检索 | 一个入口搜遍任务、项目、灵感、资料 |
| 设置 | 千问智能拆解、GitHub 同步、导入/导出/清空 |

## 自动拆解（两级智能）
- **规则引擎**（默认，离线可用）：新建项目按分区阶段模板自动铺里程碑；
  记任务勾选拆解按剩余天数生成步骤；灵感按关键词归类。
- **千问增强**（设置页配好中转后自动启用）：项目创建后按你的标题与目标
  **重排专属阶段**；灵感归类异步精修。任何网络失败都静默回退规则，页面不卡不坏。

## 数据与安全
- 未开同步时数据只存本机浏览器；开同步后存你的 **GitHub 私有 Gist**（只含书房数据，
  不含 Token / 密钥——它们永远只存各设备本机）。
- 千问 API Key 存在你自己函数计算的环境变量里，浏览器拿不到。
- 清理浏览器记录会丢本机数据：常按「设置 → 导出 JSON」备份，或开启同步。
- 多端冲突策略为"较新保存者覆盖"，单人使用几乎不会触发。
